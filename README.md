# Land der Sonne

Ambitious top-down pixel-art fantasy sandbox RPG with a persistent, simulated world.

## Project status
**Phase 0: research and technical foundations.** No gameplay, engine integration, graphics, tests, or playable build is claimed yet.

## Design pillars
1. High-quality, consistent, original top-down pixel art.
2. A persistent world where NPCs, economies, ecosystems and factions affect one another.
3. Player freedom through interconnected systems, not merely inflated content counts.
4. Deterministic generation, reproducible saves and evidence-based quality gates.
5. A modular architecture and durable, versioned project knowledge.
