# Initial data contracts

## World state v1
JSON object with integer `version`, integer `seed`, nonnegative integer `tick`, and dictionary `flags` mapping nonempty string IDs to booleans.

This is a prototype contract, not a final production save schema. Future contracts need stable entity IDs, migrations, backups, checksums, chunk deltas and explicit failure recovery.

## Coordinates
Terrain coordinates use signed Vector2i cells. Chunks are 64x64 cells, with floor division for negative positions and positive local coordinates in [0, 63].

## Determinism
The same seed and coordinates must produce the same terrain classification. A stable terrain function is not sufficient to establish deterministic NPC simulation or cross-platform save reproducibility.

## Separation
WorldState and Terrain must remain independent of rendered scenes. Scene scripts may reference these modules; the world simulation must not depend on scene nodes.

## Galactic world contract — observed prototype v1 (2026-11-11)

The legacy terrain contracts above remain for the preserved fantasy foundation only. The active galactic world is generated by `GalaxyModel.generate(settings, empire)` and has a **different schema**.

### Authoritative core fields
- `version`: current `GalaxyModel.VERSION = 1`; `settings.seed` is the actual persisted RNG seed; `tick` is nonnegative.
- `stars`: array indexed by stable integer `star.id` from 0 to N-1; `owner = -1` is unclaimed, `0` is player, positive IDs refer to `ai[].id`.
- `ai`: rival identity and capital records; `empire`: player identity. `history`: chronological string array.
- `credits`, `science`: player aggregate balances; `alloys` added by `GalaxyStrategy.prepare`; `industry` added by `GalaxySystems.prepare`.
- `civilian_worlds`: stringified star ID -> market dictionary (`population`, `capacity`, `jobs`, `satisfaction`, `private_capital`, `goods`, `output`, `taxes`). `civilian_trade` is an array of `{from,to,goods}`.
- `ai_societies`, `ai_intentions`, `ai_treasury` use stringified rival IDs; `milestones` is an array of stable goal IDs.
- Save serialization is JSON; loaded objects are validated in `GalaxyModel._read` for format and basic settings only. `GalaxyContracts.errors(world)` currently offers **additional read-only structural diagnostics**, but is not yet a mandatory load gate.

### Tick ownership and order (observed)
1. `GalaxyStrategy.prepare` calls `GalaxySystems.prepare`, `GalaxyAI.prepare`, `GalaxyCivilians.prepare`, `GalaxyProgress.prepare` and adds optional strategic fields.
2. `GalaxyStrategy.tick` snapshots treasury and then calls `GalaxySystems.tick`: `GalaxyModel.advance` increments tick and grants base credits/science; lore, exploration, ambient events, fleet movement, owned-star revenue, industry and AI treasury are updated.
3. `GalaxyCivilians.tick` advances population, production, goods, satisfaction, private capital, civilian tax statistics, shipments and migration.
4. `GalaxyStrategy.tick` applies buildings, tax policy modifiers, focus, artifacts, stability and diplomatic trust.
5. `GalaxyAI.tick` advances rival society, fleets, expansion and conflict.
6. `GalaxyProgress.tick` awards persistent milestones; economy history is updated.

**These are current implementation observations, not a finalized transaction model.** All domains currently mutate shared Dictionaries; they do not yet have formal write ownership, a transaction ledger, or separate deterministic RNG streams.

### Integrity requirements / explicit gaps
- Every star ID matches its array index; every owner is either -1, 0 or a known rival; IDs remain stable across save/load.
- All civilian stocks, populations, capacities and accounts must remain nonnegative; population may not exceed capacity; freight endpoints and quantities must be valid.
- A generated game with the same seed, settings and inputs must replay identically; new regression tests cover a limited 12-tick case, not all platforms or long-running games.
- **Not yet satisfied:** full goods conservation ledger; explicit debit/credit transfers between private households, firms and state; single-source tax accounting; transactional command processing; schema migrations beyond save v1; per-subsystem PRNG streams; comprehensive negative/corrupt-save validation.
- **Observed accounting caveat:** `GalaxyCivilians.tick` calculates `civilian_taxes` but does not credit them to the state; `GalaxyStrategy.tick` separately grants a policy-dependent tax amount. This is not yet a reconciled fiscal model. Do not credit both without replacing the legacy policy income.
- **Observed timing caveat:** `civilian_approval` is calculated before migration is applied, so the displayed weighted average can lag behind the final population distribution. Correct in a later cohesive population/economy slice with tests.
- **Observed mechanics caveat:** galaxy travel currently uses Euclidean distances; guaranteed graph connectivity and interstellar communication delay are not implemented.

### Validation levels
1. **Structural:** `GalaxyContracts.errors` detects selected schema/ID/stock violations.
2. **Simulation regression:** `game/tests/galaxy_contracts_test.gd` compares two fixed-seed simulations over 12 ticks and checks persistence.
3. **Economic conservation:** NOT YET IMPLEMENTED. Requires an explicit ledger and production/consumption/transfer assertions.
4. **Native gameplay, visual quality and performance:** NOT established by these tests.

All above validations must run in CI and pass before a requirement is checked off in the independent mandatory checklist.
