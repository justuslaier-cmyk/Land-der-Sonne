# Visual acceptance gate v0.1

The current rendered scene is a **debug prototype**, not the approved art direction.

## Required production visual prototype
- True top-down camera, consistent 2D pixel scale and nearest-neighbor filtering.
- Original hand-authored or appropriately licensed pixel-art environment with trees, buildings, paths and props.
- Readable character silhouettes, animations and collision alignment.
- No mismatched tile edges, placeholder circles, obvious visual repetition or arbitrary palette shifts.
- Multiple lighting situations and viewport sizes.
- Engine-rendered screenshots, checked at native resolution and common scaling factors.
- Clear provenance and licensing for each asset.

## Automation boundaries
A screenshot capture proves that rendering occurred, not that the art is attractive. Automated pixel-diff checks can catch regressions only after a human-approved reference exists.
